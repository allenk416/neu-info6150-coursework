# Movie Finder

Movie Finder is the final project for Northeastern's INFO 6150 — Web Design and
User Experience Engineering. It presents curated movie collections, rotating
popular and trending titles, a responsive poster layout, and a movie search
interface.

The project uses semantic HTML, CSS, vanilla JavaScript, and a small Node.js
API proxy. The browser sends searches to a same-origin endpoint, so provider
credentials stay on the server. Search results are rendered with DOM text APIs
and validated poster URLs.

The search service needs a deployed Node runtime and a rotated RapidAPI
credential set in the server environment. The static pages remain usable as a
visual showcase while that service is unavailable. No credentials are stored
in this project snapshot.

This folder is a sanitized snapshot of [the original FinalProject repository](https://github.com/allenk416/FinalProject).
The source repository remains the place to view the original project history.
