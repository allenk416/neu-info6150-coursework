# Northeastern INFO 6150 Coursework

A collection of eight assignments from **INFO 6150 — Web Design and User
Experience Engineering** at Northeastern University.

The coursework covers HTML, CSS, vanilla JavaScript, responsive layouts,
browser events, form validation, dynamic DOM rendering, and the Fetch API.

## Assignments

| Assignment | Content | Entry point |
| --- | --- | --- |
| [HW01](hw01/) | A starter page with CSS styling and JavaScript console output | [index.html](hw01/index.html) |
| [HW02](hw02/) | Addition and multiplication calculators with navigation between pages | [a.html](hw02/a.html), [m.html](hw02/m.html) |
| [HW03](hw03/) | A library website with a catalog, simulated login and borrowing, and a library card form | [home.html](hw03/home.html) |
| [HW06](hw06/) | A later library website version with responsive styling and search input validation | [index.html](hw06/index.html) |
| [HW07](hw07/) | An informational page with a high-contrast mode | [HW7.html](hw07/HW7.html) |
| [HW08](hw08/) | Dynamic rendering of countries and subdivisions from nested geography data | [index.html](hw08/index.html) |
| [HW09](hw09/) | A registration form with conditional ZIP code fields and input validation | [HW9.html](hw09/HW9.html) |
| [HW11](hw11/) | Random dog images requested through the Fetch API | [hw11.html](hw11/hw11.html) |

## Course Final Project

[Movie Finder](https://github.com/allenk416/FinalProject) is the final project
for the same course. It is maintained separately and is not included in this
collection.

## About This Collection

The original assignments are preserved in separate folders, including similar
code from different stages of the course. Their original Git commits are
retained within this repository.

These are classroom exercises. Login, borrowing, and form submission examples
simulate interactions in the browser rather than providing backend services.
In the preserved HW06 version, the borrowing handler references missing page
elements. HW11 depends on an external API and has limited error handling.
